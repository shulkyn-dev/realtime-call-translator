# База знаний для ИИ-агента

Эти файлы — «мозг» помощника. Когда на созвоне/собеседовании клиент задаёт вопрос,
агent берёт отсюда нужные факты и подсказывает тебе ответ **про тебя** (на английском
и русском). Чем подробнее и честнее заполнишь — тем точнее подсказки.

## Что это НЕ
- Это **не обучение модели**. Мы ничего не тренируем. Файлы просто подкладываются
  Claude как контекст при каждом вопросе. Значит: правишь файл — агент сразу «знает»
  новое, без пересборки.
- Это **не сервер**. Обычные файлы на твоём диске.

## Как заполнять
- Пиши простым языком, фактами. Короткие абзацы, списки — лучше сплошного текста.
- Можно на русском — агент сам сформулирует ответ на нужном языке.
- Не выдумывай: если чего-то не знаешь/не делал — не пиши. Агент не должен врать на собесе.

## Файлы
| Файл | Что внутри |
|---|---|
| `about_me.md` | Кто ты: роль, опыт в цифрах, чем ценен, к какой позиции идёшь |
| `skills.md` | Навыки: инструменты, технологии, уровень, годы |
| `experience.md` | Опыт работы: где, кем, что делал, результаты |
| `projects.md` | Проекты/кейсы: задача → что сделал → результат (цифры!) |
| `interview_qa.md` | Частые вопросы собеса и твои готовые ответы |

Заполни что сможешь. Можно просто скинуть резюме/портфолио — разложу по файлам.
